# Plateforme intelligente d'auto-évaluation de la maturité cybersécurité des PME

## Description

Cette plateforme permet aux PME marocaines d'évaluer leur niveau de maturité en cybersécurité à travers un questionnaire interactif basé sur les bonnes pratiques de sécurité.

## Fonctionnalités réalisées

- Authentification des PME
- Création d'un compte
- Questionnaire d'auto-évaluation
- Calcul du score global
- Calcul des scores par catégorie
- Détermination du niveau de maturité
- Affichage des résultats
- recommandations personnalisés
- Enregistrement des résultats dans MySQL
- Génération du rapport PDF de diagnostic
## Technologies utilisées

- Python
- Streamlit
- MySQL
- mysql-connector-python
- Pandas
- bcrypt

## Installation

```bash
pip install -r requirements.txt
```

## Lancement

```bash
streamlit run app.py
```
